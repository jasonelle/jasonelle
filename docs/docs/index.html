Jasonelle Documentation

Write for the Web. Ship Native.

Jasonelle is a native wrapper for your web application. Build native iOS and Android apps from your existing web application, with a bidirectional JavaScript-to-native bridge and an extensible plugin architecture.

What is Jasonelle?

Jasonelle wraps your web application into a native iOS and Android app, so you keep writing with the web technologies you already know and ship it as a native app. Your web frontend runs inside a native container, connected to the platform through a bidirectional bridge:

  • JavaScript to native: your web app can call native features — device APIs, native UI, plugins, and more.

  • Native to JavaScript: native code can push data and events back into your web app.

Because the bridge and the plugin system are extensible, Jasonelle grows with the capabilities your app needs, without leaving the web.

Releases

The current version is v4. The latest releases are available at Jasonelle GitHub Releases.

A legacy version is also available for older Jasonette/Jasonelle (v1, v2, v3) features, but they are without official support.

License

Jasonelle is dual licensed: AGPLv3 or MPLv2.

Without a license key, Jasonelle is licensed under AGPLv3 and will not execute on real devices (though full mode can be activated for testing). With a valid Jasonelle Key, purchased from the official Jasonelle Store, the MPLv2 license applies and real device execution is allowed.

Some features, such as GPS, require real hardware to test. Please purchase a license if you use Jasonelle in your projects.
