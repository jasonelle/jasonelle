Write for the Web. Ship Native.

Jasonelle wraps your web application into a native iOS and Android app. Keep the web technologies you already know and ship a real native app, with a bidirectional JavaScript-to-native bridge.

// your web app calls native features
const device = await window.jasonelle.plugins.device.info();
console.log(device.platform);  // "ios" | "android"

// native pushes an event back into your app
window.jasonelle.plugins.hello.handle = ({ event, ...payload }) => {
  if (event === "ContentView.onAppear") cart.refresh(payload);
});
Why Jasonelle

Your Web App Is Already the App

Your frontend runs inside a native container connected to the platform through a bridge that goes both ways.

Native on both platforms

A SwiftUI app on WKWebView for iOS and a Kotlin Jetpack Compose app on WebView for Android.

iOS

Bidirectional bridge

JavaScript to native: device APIs, native UI, plugins. Native to JavaScript: code pushes data and events back into your app.

Architecture

Extensible plugins

Native capabilities are plugins. Add the ones your app needs and Jasonelle grows with it, without leaving the web.

Create one

One command to build

task gen assembles a complete, configured Xcode and Android Studio project from the same sources.

The pipeline
The Pipeline

Two Platforms, One Set of Inputs.

lib/common/ is the base layer. Platform directories override or extend it, same path, platform wins. Drop a file in lib/<platform>/sources/ and it replaces the stock file during the build.

After the last step each build/<platform>/ directory holds a complete native project ready to open and build.

Read the architecture
task gen
  • 1
    icon App icons for both platforms from one 1024px PNG
  • 2
    jsonc Merges the cascading config.jsonc and store.jsonc
  • 3
    bundler Bundles TypeScript into a single webview.js
  • 4
    plugins Copies only the plugins you configured
  • 5
    core Assembles the source tree, applying overrides
  • 6
    link Links plugins into the native projects
  • 7
    appconf Sets bundle ID, app name, version and build number
Plugins

Native Capabilities, One Call Away

Every plugin is callable from your web code as window.jasonelle.plugins.<name>.

Device

Device information straight from the platform, iOS and Android.

plugins.device.info()

Apple Sign In

Sign in with Apple through AuthenticationServices, plus a native button. iOS only.

plugins.appleSignIn()

Cookies

Persist web view cookies in the iOS Keychain and Android EncryptedSharedPreferences.

plugins.cookies.save()

OpenTelemetry

Counters and histograms from inside the app, on both platforms.

plugins.opentelemetry.counter()

Hello

The sample plugin. Read it end to end to learn how the bridge works.

plugins.hello.call()

Your own

Subclass the plugin base, declare it in your config and task gen wires it into both projects.
