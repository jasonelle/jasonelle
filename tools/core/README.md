# Core

Assembles the application source tree into `build/<platform>/sources/`, mixing
the stock Jasonelle sources with your overrides. Run it after `task jsonc`,
`task bundler` and `task plugins` so generated files are not clobbered.

For each platform, `build/<platform>/sources/<rel>` is resolved with the
following precedence (highest first):

1. `lib/<platform>/sources/<rel>` — your override, always wins.
2. An existing file at the destination — e.g. `Plugins.swift` / `Plugins.kt`
   generated by the plugins tool.
3. `sources/<platform>/<rel>` — the stock core file.

Top-level `JLPlugin*` directories in the stock sources are skipped: the
plugins tool owns copying and selecting plugins, so this tool does not bring
back plugins that were removed from the config. Overrides for those plugins
under `lib/<platform>/sources/JLPlugin*/` are still applied.

The tool never deletes anything, so files placed in `build/<platform>`
by the other tools are preserved.

## Usage

From the repository root:

```
tools/core/dist/core-<os>-<arch>
```

With default paths it assembles both platforms. Flags:

- `--xcode` (default `sources/xcode`): Xcode core sources.
- `--android` (default `sources/android`): Android core sources.
- `--xcode-lib` (default `lib/xcode/sources`): Xcode override sources.
- `--android-lib` (default `lib/android/sources`): Android override sources.
- `--only xcode|android`: assemble a single platform.

## Building from source

From `tools/core/src`:

- `task build` (`b`) cross-compiles binaries into `tools/core/dist/`
- `task test` (`t`) runs the test suite
