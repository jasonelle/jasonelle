= App Configuration (Android)

Jasonelle controls application settings and plugin registration through `config.jsonc`.

== Overview

The build pipeline merges `lib/common/config/config.jsonc` with `lib/android/config/config.jsonc`.
The merged output is written to `build/android/config/config.jsonc`.
Downstream tools use this file to configure the Android project and copy plugins.

Run the following command to merge the configuration files:

[source,bash]
----
task jsonc.android
----

== File Locations

* `lib/common/config/config.jsonc`: Baseline application settings and plugins.
* `lib/android/config/config.jsonc`: Android specific settings and overrides.
* `build/android/config/config.jsonc`: Merged file consumed by the build pipeline.

== Common Configuration (lib/common/config/config.jsonc)

The `lib/common/config/config.jsonc` file defines common application settings across platforms.

=== Configuration Properties

[cols="1,1,2"]
|===
|Property |Type |Description

|`url`
|String
|The initial URL loaded inside the main web view.

|`app_id`
|String
|The application identifier (for example, `com.example.application`).

|`app_name`
|String
|The application display name shown below the launcher icon.

|`app_version`
|String
|The base application version (for example, `1.0`). The build number is the current Unix timestamp, so the version becomes `1.0.<timestamp>`. In Android `app_version` becomes `versionName` and the timestamp becomes `versionCode`.

|`inspectable`
|Boolean
|Enables remote web debugging through Chrome DevTools.

|`allowed`
|Array of Strings
|Allowed domain hostnames for internal navigation.

|`plugins`
|Object
|Map of registered plugins and their source locations.
|===

=== Domain Whitelist (allowed)

The `allowed` array controls web view navigation:

* When empty or omitted, all URLs open inside the main web view.
* When domains are present, only matching hostnames load inside the main web view.
* External links not matching the whitelist open in the system default browser.

=== Plugin Resolution

The `plugins` object maps plugin class names to location specifiers:

* `@jasonelle`: Core plugin present in both Android and Xcode templates (`sources/android/` and `sources/xcode/`).
* `@jasonelle/android`: Core plugin present only in the Android template (`sources/android/`).
* `@lib/<PluginName>`: Custom workspace plugin located at `lib/common/sources/plugins/<PluginName>`.
* `@lib/android/<PluginName>`: Custom Android plugin located at `lib/common/sources/plugins/<PluginName>/android`.

=== Common Configuration Example

[source,jsonc]
----
{
  "url": "https://jasonelle.com",
  "app_id": "com.example.application",
  "app_name": "Jasonelle v4",
  "app_version": "1.0",
  "inspectable": true,
  "allowed": ["github.com"],
  "plugins": {
    "JLPluginCookies": "@jasonelle",
    "JLPluginDevice": "@jasonelle"
  }
}
----

== Android Configuration (lib/android/config/config.jsonc)

The `lib/android/config/config.jsonc` file specifies overrides and settings specific to Android.
Empty objects inherit all values from common configuration.

=== Android Configuration Example

[source,jsonc]
----
{
  "inspectable": true
}
----

== Merged Output (build/android/config/config.jsonc)

The following example shows the resulting merged file after running `task jsonc.android`:

[source,jsonc]
----
{
  "allowed": [
    "github.com"
  ],
  "app_id": "com.example.application",
  "app_name": "Jasonelle v4",
  "app_version": "1.0",
  "inspectable": true,
  "plugins": {
    "JLPluginCookies": "@jasonelle",
    "JLPluginDevice": "@jasonelle"
  },
  "url": "https://jasonelle.com"
}
----

== Pipeline Integration

Downstream build tools consume `build/android/config/config.jsonc`:

* `tools/appconf`: Reads `app_id` to update `applicationId` in `build.gradle.kts` and package references in `AndroidManifest.xml`. Reads `app_name` to update the application label string. Reads `app_version` to set `versionName` and a timestamped `versionCode` (the build number).
* `tools/plugins`: Reads `plugins` to copy declared plugin code into `build/android/sources/`.
