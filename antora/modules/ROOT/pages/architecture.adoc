= Architecture

This document outlines the architecture for the Jasonelle cross-platform web wrapper generator framework.

== Architecture Overview

The system is designed around a strictly separated directory structure, a modular CLI approach, and a cascading asset injection strategy.

1. *System Requirements*: Xcode generation requires an Apple Silicon (ARM) Mac and targets iOS 26 or higher. Android generation is cross-platform.
2. *Main Orchestrator (`gen`)*: A Go-based CLI tool responsible for orchestrating the generation process. It merges cascading configurations from `lib/` and delegates tasks to platform-specific CLIs.
3. *Platform CLIs*: `android` (Go) for Android projects and `xcode` (Swift) for Xcode projects.
4. *Cascading Configuration & Assets*: A layered asset injection system where `lib/common/` serves as a base, and platform directories (`lib/xcode/`, `lib/android/`) override or extend those assets.
5. *Native File Overrides*: Placing a file in `lib/<platform>/sources/` will automatically overwrite the base template from `sources/<platform>/` during the build.
6. *Store Metadata Handling*: A `config/store.jsonc` and `lib/common/.env` file manage store metadata and secrets. A dedicated `fastlane-gen` tool parses these to output Fastlane-ready files into `build/fastlane/`.
7. *JavaScript Bundling*: Uses `esbuild` to merge Javascript files from plugins, `lib/common`, and `lib/<platform>` into a single `webview.js` asset while preserving the cascading execution order via dynamically generated entry points.

== Directory Structure

* `.gitignore`: Excludes `.env` and `build/`.
* `sources/`: Base project templates.
* `lib/`: User workspace for configurations.
** `lib/common/`: 
*** `.env`: Secret keys for tools and stores.
*** `config/config.jsonc`: Foundational configuration.
*** `config/store.jsonc`: Shared app store metadata.
*** `icon/1024x1024.png`: High-res base icon.
*** `resources/`: Raw files copied to the app bundle.
*** `scripts/main.js`: Base JavaScript bridge logic.
** `lib/android/`:
*** `config/config.jsonc`: Android configuration overrides.
*** `config/store.jsonc`: Play Store specific overrides.
*** `scripts/main.js`: Android JavaScript overrides.
*** `sources/`: Native file replacements (e.g., custom `MainActivity.kt`).
** `lib/xcode/`:
*** `config/config.jsonc`: Xcode configuration overrides.
*** `config/store.jsonc`: App Store specific overrides.
*** `scripts/main.js`: Xcode JavaScript overrides.
*** `sources/`: Native file replacements (e.g., custom `ContentView.swift`).
** `lib/plugins/`: User-provided custom plugins.

* `tools/`: CLI Tools.
** `tools/gen/`: Main orchestrator CLI source code (Go).
** `tools/android/`: Android configuration CLI source code (Go).
** `tools/xcode/`: Xcode configuration CLI source code (Swift).
** `tools/fastlane-gen/`: Generates Fastlane automation files (Go).
** `tools/icon-gen/`: Utility for generating app icons (Go).

* `build/`: The output destination.
** `build/xcode/`: The generated Xcode project.
** `build/android/`: The generated Android Studio project.
** `build/fastlane/`: Ready-to-use Fastlane automation files.

== Fastlane

`fastlane-gen` generates standard Ruby-based Fastlane files 
(a Fastfile, Appfile, and Deliverfile/Supplyfile). This way, 
developers familiar with Fastlane can easily inspect, debug, and run standard 
fastlane release commands, 
rather than relying on a giant, 
hard-to-read bash script with dozens of CLI arguments.
