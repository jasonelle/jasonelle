https://github.com/jasonelle/jasonelle[Jasonelle] is a native wrapper for your
web application. Build native iOS and Android apps from your existing web
application, with a bidirectional JavaScript-to-native bridge and an extensible
plugin architecture.



== What is Jasonelle?

Jasonelle wraps your web application into a native *iOS* and *Android* app, so you
keep writing with the web technologies you already know and ship it as a native
app. Your web frontend runs inside a native container, connected to the platform
through a bidirectional bridge:

* *JavaScript to native*: your web app can call native features -- device APIs,
  native UI, plugins, and more.
* *Native to JavaScript*: native code can push data and events back into your web
  app.

Because the bridge and the plugin system are extensible, Jasonelle grows with the
capabilities your app needs, without leaving the web.

*Without* a license key, Jasonelle is licensed under _AGPLv3_ and will *not* execute
on real devices (though full mode can be activated for testing).
*With* a valid https://jasonelle.gumroad.com/[Jasonelle Key], purchased from the

applies and real device execution is allowed.

Some features, such as _GPS_, require real hardware to test. Please purchase a
license if you use Jasonelle in your projects.
